## SQL cause

The two complete queries are preserved from the trace in [faulty-gpt-oss-20b.sql](faulty-gpt-oss-20b.sql) and [faulty-dots.sql](faulty-dots.sql). Both have valid joins and correctly multiply quantity by price. Their age filters are wrong:

```sql
-- GPT-OSS 20B
WHERE c.birth_date >= '2001-09-24'
  AND c.birth_date <  '2001-09-25';

-- Dots
WHERE c.birth_date = '2001-09-24';
```

The dataset stores birth dates as `YYYY-MM-DD`. Consequently, both filters select only people born on **2001-09-24**, whose 25th birthday is exactly the reference day. Both queries execute and return **25,920 cents**.

Being exactly 25 on 2026-09-24 means that the 25th birthday has occurred but the 26th has not. The correct birth-date window is:

```sql
WHERE c.birth_date > '2000-09-24'
  AND c.birth_date <= '2001-09-24'
```

Someone born on 2000-09-24 is already 26 and must be excluded; someone born on 2000-09-25 is still 25 and must be included. The [complete reference SQL](reference.sql), copied from the team's reference file, calculates completed age with the year difference minus the birthday adjustment and returns **605,580 cents**. All orders of qualifying customers count; there is no order-date restriction in C08.

## Executed delta query

[delta.sql](delta.sql) selects customers in the correct age window who are absent from both faulty selections, then sums each customer's order-line revenue. Executed on the manifest-verified `data/boutique.sqlite`, it produces [delta-customers.csv](delta-customers.csv):

The faulty selection is a subset of the correct selection, so there are no wrongly added customers. The five omitted customers explain the entire difference:

**605,580 − 25,920 = 579,660 cents (€5,796.60).**

## Conclusion and limits

Two models can share the same age-boundary mistake while producing syntactically valid SQL. Quorum agreement is evidence of agreement, not a guarantee of truth. An independent deterministic reference and a query isolating the missing rows establish the error here. This single batch does not measure a general quorum error probability.
