# TD1 / explanation

One file per model, written by its operator: `explanations-X.csv` (X = A to E). One row per question C01–C20 with the final status, the model's value, the reference and the cause read in the returned SQL (`cause_category`, `explanation`).

Used to build [`../results/model-question-comparison-en.csv`](../results/model-question-comparison-en.csv).
